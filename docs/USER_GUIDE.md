# BlindPath 用户手册

## 智行助盲 - 视障人士出行助手

版本：v3.4  
最后更新：2024年

---

## 📱 应用简介

BlindPath（智行助盲）是一款专为视障人士设计的智能出行辅助应用，通过 AI 技术实时检测障碍物，结合 GPS 导航和语音播报，帮助用户安全出行。

### 主要功能

| 功能 | 说明 |
|------|------|
| 🚧 障碍物检测 | 实时检测前方行人、车辆、台阶等障碍物 |
| 🧭 智能导航 | GPS 定位 + 语音导航指引 |
| 🎙️ 语音播报 | 全程语音反馈，无需看屏幕 |
| 📳 振动预警 | 多级别振动提醒危险程度 |
| 🆘 SOS 求助 | 一键发送位置给紧急联系人 |
| 🏠 室内识别 | 识别室内环境和家具 |

## 📖 功能使用指南

### 1. 障碍物检测

**使用方法**：
1. 点击首页「障碍物检测」按钮
2. 将手机背面朝前，握在胸前
3. 缓慢行走，应用会自动检测障碍物

**语音提示**：
| 提示内容 | 含义 | 建议 |
|---------|------|------|
| "前方有行人" | 1-3米内有行人 | 减速，注意避让 |
| "前方有车辆" | 检测到汽车 | 停止前进，确认安全 |
| "前方有台阶" | 检测到台阶或楼梯 | 小心脚下 |
| "危险！前方有障碍物" | 1米内有障碍物 | 立即停止 |

**振动模式**：
- ⚡ 三次急促振动 = 危险（立即停止）
- ⚡⚡ 两次中等振动 = 警告（注意观察）
- ⚡ 一次轻微振动 = 安全提示

---

### 2. 导航功能

**设置目的地**：
1. 点击「导航」按钮
2. 语音输入或手动输入目的地
3. 确认路线后开始导航

**导航中的语音提示**：
- "向东走50米" - 行走方向和距离
- "前方路口左转" - 转弯提示
- "已偏离路线，正在重新规划" - 偏航提醒
- "GPS信号弱，请注意周围环境" - 定位精度提醒

**GPS 精度说明**：
| 精度 | 语音提示 | 建议操作 |
|------|---------|---------|
| 优秀（<5米） | 无 | 正常使用 |
| 良好（5-10米） | "定位精度良好" | 正常使用 |
| 一般（10-20米） | "定位精度一般" | 多观察周围环境 |
| 较差（>20米） | "GPS信号弱" | 停止导航，寻找地标 |

---

### 3. SOS 求助

**设置紧急联系人**：
1. 进入「设置」→「紧急联系人」
2. 添加联系人姓名和电话号码
3. 最多可设置 3 个紧急联系人

**使用 SOS**：
1. 长按首页 SOS 按钮 3 秒
2. 或连续按电源键 5 次
3. 应用自动发送短信，包含：
   - 当前位置（地图链接）
   - 预设的求助信息
   - 电池电量

---

### 4. 室内环境识别

**使用方法**：
1. 点击「室内识别」按钮
2. 缓慢移动手机扫描周围环境
3. 应用会语音描述当前场景

**可识别场景**：
- 🛋️ 客厅
- 🛏️ 卧室
- 🍳 厨房
- 🚿 卫生间
- 📇 走廊
- 🚪 门/出口

---

### 5. 语音交互

**语音命令**（在任意界面）：
| 命令 | 功能 |
|------|------|
| "开始检测" | 启动障碍物检测 |
| "停止检测" | 停止检测 |
| "导航到[地点]" | 开始导航 |
| "停止导航" | 停止导航 |
| "SOS" | 触发紧急求助 |
| "电量多少" | 语音播报电池电量 |
| "现在几点" | 语音播报当前时间 |

## ⚙️ 设置选项

### 无障碍设置

| 选项 | 说明 |
|------|------|
| 字体大小 | 调整界面文字大小（小/中/大/特大） |
| 高对比度模式 | 增强界面对比度，更易辨识 |
| 振动强度 | 调整振动反馈强度 |
| 语音速度 | 调整播报语速（慢/正常/快） |

### 检测设置

| 选项 | 说明 |
|------|------|
| 检测灵敏度 | 低/中/高三档灵敏度 |
| 预警距离 | 设置开始预警的距离（1-5米） |
| 检测对象 | 选择要检测的对象类型 |

### 导航设置

| 选项 | 说明 |
|------|------|
| 导航语音 | 选择导航播报详细程度 |
| 偏航提醒 | 偏离路线时提醒频率 |
| 省电模式 | 降低定位频率以省电 |

## 🔋 省电技巧

1. **开启省电模式**
   - 设置 → 导航 → 省电模式

2. **降低检测灵敏度**
   - 设置 → 检测 → 灵敏度设为"低"

3. **减少检测对象**
   - 设置 → 检测 → 只选择必要的对象类型

4. **使用耳机**
   - 降低扬声器功耗

5. **关闭不必要的功能**
   - 不使用时关闭导航

## ❓ 常见问题

### Q: 检测不到障碍物？
**A:** 
1. 确认相机权限已开启
2. 检查摄像头是否被遮挡
3. 确保环境光线充足
4. 尝试重启应用

### Q: GPS 定位不准？
**A:**
1. 确保位置权限为"始终允许"
2. 到开阔区域等待 GPS 信号
3. 检查手机 GPS 是否开启
4. 关闭 WiFi（某些情况下会干扰）

### Q: 语音播报不工作？
**A:**
1. 检查手机音量是否开启
2. 确认 TTS 引擎已安装
3. 尝试更换 TTS 语言设置

### Q: 应用耗电快？
**A:**
1. 开启省电模式
2. 降低检测灵敏度
3. 不使用时关闭应用

### Q: 如何更新 AI 模型？
**A:**
应用会自动检查更新，也可手动触发：
设置 → 关于 → 检查更新
