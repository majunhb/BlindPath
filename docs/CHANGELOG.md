# 更新日志

## [1.0.0] - 2026-05-18

### ✨ 新功能
- 🎯 **障碍物检测** - 实时检测前方障碍物并语音预警
- 🗣️ **语音播报** - 全程语音引导，支持语速调节
- 🧭 **导航指引** - 步行导航，播报转向和距离
- 🌤️ **天气播报** - 实时天气信息，出行建议
- 🆘 **紧急求助** - 一键 SOS，发送位置短信
- 👥 **社区互助** - 寻找志愿者陪伴出行
- 🗺️ **路线规划** - 无障碍路线规划，支持公共交通

### 🎨 设计
- 视障友好界面设计
- 大按钮、高对比度颜色
- 全程语音反馈

### 🛠️ 技术
- Kotlin + Jetpack Compose
- MVVM + Clean Architecture
- Hilt 依赖注入
- Material Design 3
