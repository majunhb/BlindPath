### 安全建议

1. **定期更新**：建议每季度检查依赖更新
2. **依赖扫描**：集成 OWASP Dependency Check
3. **锁定版本**：使用版本目录管理依赖

## 更新计划

### 阶段1：低风险更新（立即执行）
- Kotlin 1.9.20 → 1.9.22
- CameraX 1.3.1 → 1.3.2
- Lifecycle 2.6.2 → 2.7.0

### 阶段2：中风险更新（测试后执行）
- AGP 8.2.0 → 8.3.0
- Compose BOM 2023.10.01 → 2024.02.00
- Hilt 2.48 → 2.50

### 阶段3：高风险更新（充分测试后执行）
- TensorFlow Lite 2.14.0 → 2.15.0
- Play Services Location 21.0.1 → 21.1.0

## 执行命令

```bash
# 检查依赖更新
./gradlew dependencyUpdates

# 安全漏洞扫描
./gradlew dependencyCheckAnalyze

# 执行更新
# 手动修改 build.gradle.kts 中的版本号
```

## 版本锁定文件

建议创建 `gradle/libs.versions.toml` 统一管理版本。
